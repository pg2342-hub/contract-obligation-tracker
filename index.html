Contract Obligation Tracker

A model extracts each obligation and the clause it comes from. Code computes the dates. A person checks every field before anything reaches the deadline calendar.

Demo on sample agreements with fictional parties, built on Common Paper templates (CC BY 4.0). Review choices are saved only in this browser. Not legal advice.

How it works

  1. Extract. tools/extract.py sends an agreement to Claude, which returns key terms (dates, terms, notice periods) and obligations as structured data. Each item carries the exact clause it relies on. The model never computes a date; it describes a rule, such as "30 days before each anniversary of the Order Date."
  2. Check automatically. tools/build_schedule.py confirms that every quoted clause appears word for word in the source document and that every key term's value matches its own quote, for example that "January 5, 2026" really is 2026-01-05. Then it computes each deadline from the rule. Any failure stops the build, and CI runs this check on every push.
  3. Verify by hand. Every obligation starts as unverified. A reviewer opens the source clause, confirms the owner, the date rule and its reading of the contract, and the action, then signs off. A wrong item is rejected with a reason.
  4. Alert only on verified items. The deadline calendar, the alerts and the calendar export include verified obligations only. An unverified deadline is counted but never shown as reliable.

Why a person checks every field

A missed renewal or notice date can cost a full contract year. Sampling a share of extractions would be faster, but a single miss is the failure that matters, so this design checks 100% of fields and uses automation to make each check quick: the clause is one click away and highlighted.

Date conventions

Notice deadlines are read conservatively, because a notice that arrives one day late is a missed notice. A 12-month term runs through the day before its anniversary. A notice date "at least N days before the end" is N calendar days before that last day, and where notice must arrive before that date, the tracker shows the day before it as the last safe day. Each dated obligation states its reading of the contract in plain words, and the reviewer confirms that reading as part of the date check. A clause that can be read two ways goes to a lawyer.
